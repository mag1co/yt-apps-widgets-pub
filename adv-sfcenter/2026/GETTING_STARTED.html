Requirements

YouTrack 2026.2 or later.

On YouTrack 2025.x? Use the latest 2.8.x version of the app. Open the Versions tab on this Marketplace page, download the latest 2.8.x release, and upload the ZIP in YouTrack via Administration → Apps.

1. Install the app

Upload the app ZIP to your YouTrack instance via Admin → Apps.

2. Enable for a project

Go to Project Settings → Portal tab. Click Enable Service Center for the project.

Project Admins (users with UPDATE_PROJECT permission) can manage forms, categories, and titles. Each admin sees only the forms belonging to their own project.

3. Create forms

In the same Project Settings → Portal tab, add categories and create forms. Configure fields, mappings, and templates. Publish the form to make it visible in the portal.

Quick start: If the project has no forms yet, click "Prefill with demo data" to create sample categories and forms instantly.

4. Open Service Center

Service Portal appears in the YouTrack sidebar menu. Click it to see the catalog of published forms. Users can fill and submit forms to create YouTrack issues.

5. Settings

Administration → Apps → Adv.ServiceCenter → Settings — configure logging level (no_log, minimal, debug).

ACL Group Guard: Optionally restrict who can create All YouTrack Users and Guests (external) forms. Pick a YouTrack group for each access level — only group members will be able to select the corresponding option in the form editor. Leave empty to disable the option for everyone.

Attachments: max size per file, MB: Set this to the same value as Server Settings → Max upload file size. YouTrack does not apply its own limit to files attached by an app, so this setting is the only limit for files submitted through forms. Default is 10 MB; values above 50 MB are capped, and one submission may carry 50 MB in total.
